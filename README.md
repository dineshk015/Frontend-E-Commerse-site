🛒 E-Commerce Website

A simple and responsive e-commerce website built using HTML, CSS, and JavaScript. This project includes multiple pages such as Home, Products, and Contact, along with dynamic features like product filtering and a working cart system. Designed for clean UI, fast loading, and smooth user experience.

🚀 Features

✔️ Responsive UI for all devices

✔️ Product listing with clean card layout

✔️ Category-based filtering

✔️ Add-to-cart functionality

✔️ Separate pages (Home, Products, Contact)

✔️ Modern styling with a single shared CSS file

✔️ JavaScript used for dynamic interactions

✔️ Clean and simple navigation bar

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)
